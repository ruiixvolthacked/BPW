# 📄 BPW — Brute Force Password Wordlist

![BPW Banner](assets/gif.gif)

**BPW.py** wordlist generator tool to automatically create password lists with random variations of letters, numbers, symbols, and patterns.  
---


---

## ⚙️ Usage
pip install -r requirements.txt

python3 BPW.py

Examples:

[WARNING] Too many rows can cause a crash !!!
Enter a word > dpr kontol

Enter a line > 10

Enter special characters (press ENTER if none): @#

[INFO] Wordlist is finished [✓] : 10 row saved success
